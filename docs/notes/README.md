# Working notes (historical)

Progress logs, decisions, and post-mortems written while the experiments were
being developed. They are kept for provenance and are not maintained. For the
current state of the project start from the top-level [README](../../README.md)
and [docs/README.md](../README.md).

| File | What it records |
| --- | --- |
| `STATUS.md` | Historical status snapshot of the validation workflow |
| `TASK_STATUS.md`, `REMEDIATION_STATUS.md` | Tooling task tracker (Chinese) |
| `REMEDIATION_COMPLETE.md` | Experiment remediation report (Chinese) |
| `RECOVERY_DECISION.md`, `RECOVERY_PROGRESS.md`, `RECOVERY_COMPLETE.md` | Recovery path after the harness defect |
| `HARNESS_FIXES_V2.md`, `HARNESS_FIXED.txt` | Harness fixes applied before the formal campaigns |
| `E2_ANALYSIS.md`, `E2_POSTMORTEM.md`, `E3_COMPARISON.md` | Early experiment rounds E2/E3 |
| `NEXT_STEPS.md` | Planning notes |
| `实验文档已完成.txt` | Index of the experiment documents (Chinese) |
